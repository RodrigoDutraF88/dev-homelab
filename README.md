# dev-homelab

A real, self-hosted homelab running on a 2019 MacBook Air (Fedora, via
[t2linux](https://wiki.t2linux.org/)), built and documented as
Infrastructure as Code. This repo is both the infra definition for my
homelab and a running log of what I'm learning as I build it.

## Why

I wanted a target more real than a tutorial. A single physical machine I
own, running services I actually use, where every change is a commit and
every service is reproducible from this repo alone.
